# Havoc

Spigot **1.8.8** plugin: procedurally placed bases, breach flow with Salvage currency, shop GUI (`/havoc shop`), and timed terrain / claim reset.
## Commands

- `/havoc` — Main entry point.
- `/havoc admin` — Administrator entry point.

Havoc links against **WorldEdit 6.1.x** for compile; SaberFactions is used at runtime via a small **reflection** layer (`FactionsBridge`).
